# 経済・価格・バランス検証

[設計書一覧](README.md) / [ゲーム設計書](game-design.md)

> この文書の数値はすべて**未検証の初期パラメータ**。プレイテストやシミュレーションの結果ではない。
> 資金持ち越し、銀行、投資、連敗ボーナス、試合からVPを出さない方針は採用済み。

価格と賞金の参照元をこの文書に集約する。過去の案にあった順位VPや、下位ほど多い固定収入16/18/20/22Gは、以下の賞金＋連敗方式に置き換える。

## 2. 配置先と価格

### 2.1 カード確保

ワーカー1個で指定カード1枚を確保する。通常カードの各マスは1枠。自分の同ランク確保は1枚までの試作案。

| カード | 価格 |
| --- | --- |
| 3〜6 | 1G |
| 7〜9 | 2G |
| 10・J | 3G |
| Q・K | 4G |
| A | 5G |
| 2 | 6G |
| ♠3 | 5G。通常の3の価格を上書き |
| ジョーカー | 未決定。固定先着販売を既定にしない |

価格は通常時の強さの順だけで決め切らない。8切りの所有、革命の解禁、ペア・階段の可能性で価値が変わる。低ランクを安くしすぎた革命戦略、高ランクの割引重複を個別に検証する。

### 2.2 個人スキル

各スキルに1ラウンド1枠。購入すると永続所有し、装備している試合でだけ発動する。

| スキル | 価格 |
| --- | --- |
| 8切り | 10G |
| 11バック | 8G |
| 7渡し | 8G |
| 5スキップ | 6G |
| 9リバース | 6G |

既に所有するスキルを重複購入しても強化されない。マスは次ラウンドに空き、別の人が同じスキルを購入できる。ゲーム全体で1人しか所有できないわけではない。

### 2.3 共有ルール

購入したラウンドだけ、全員に適用する。各ルール1枠。

| 共有ルール | 価格案 | 注意 |
| --- | --- | --- |
| 階段 | 4G | 合法な連番出しを解禁 |
| 縛り | 3G | 厳密なスート条件は細則で確定が必要 |
| 方縛り | 4G | 会話中の名称。具体条件が未決定 |
| 両縛り | 6G | 上記との排他・包含関係も未決定 |
| 革命あり | 6G | 4枚出しによる反転を解禁。購入時には反転しない |

縛り系は定義が決まるまで同時購入の処理を実装しない。「共有ルール最大3種」はオプション候補であり、確定上限として扱わない。

### 2.4 銀行・投資・増員

| マス | 支払 | 効果 | 全体の枠数/ラウンド |
| --- | --- | --- | --- |
| 銀行 | 0G | 即時+4G | 2 |
| 投資 | 自分の1件目8G、2件目12G、3件目16G | 次ラウンドから1件につき毎回+2G | 2 |
| ワーカー増員 | 6個目12G、7個目20G | 次ラウンドからワーカー+1 | 1 |

どれもワーカー1個が必要。銀行で得た資金は同じ配置フェーズの後続手番で使えるが、置いたワーカーは戻らない。投資に購入ラウンドの配当は発生しない。

### 2.5 派閥支援・外交

| 到達する影響力 | 支援費用 |
| --- | --- |
| 1〜2 | 4G |
| 3〜4 | 6G |
| 5以上 | 8G |

各派閥支援は1枠。外交は全体で2枠、上の支援費用に3Gを加える。いずれも1ワーカーで影響力+1。複数段階を一括購入するマスではない。

### 2.6 勝利点

| マス・交換 | 支払 | VP | 条件・枠数 |
| --- | --- | --- | --- |
| 一般VP・小 | 7G | 1 | 全体で1枠 |
| 一般VP・中 | 15G | 2 | 全体で1枠 |
| 一般VP・大 | 24G | 3 | 全体で1枠 |
| 派閥VP・通常 | 12G | 2 | その派閥の影響力3以上 |
| 派閥VP・上級 | 19G | 3 | その派閥の影響力5以上 |
| 同盟トークン | 直接購入なし | 保持中2 | 影響力4以上で首位。移転型 |

派閥VPは**1派閥につき通常・上級で共有する1枠**。各人が一般VPを複数種類買うことは可能だが、別々の配置手番・ワーカーを使う。

一般VPは小さい交換ほど資金効率がよく、大きい交換ほどワーカー効率がよい。派閥VPの見かけの割安さは、利用資格を得るまでの支援費用・配置機会と一緒に評価する。

## 3. 試合賞金と連敗ボーナス

### 基本賞金

| 試合順位 | 基本賞金 | 試合VP | 次回の配置順 |
| --- | --- | --- | --- |
| 1位 | 20G | 0 | 1番 |
| 2位 | 12G | 0 | 2番 |
| 3位 | 10G | 0 | 3番 |
| 4位 | 8G | 0 | 4番 |

### 連敗の定義と計算

試作では「1位でなかった試合」を敗北と定義する。2位も連敗カウントを進める。この定義そのものもテスト対象。

```text
1位の場合:
    連敗数 = 0
    受取額 = 20G

2〜4位の場合:
    連敗数 = 前の連敗数 + 1
    連敗ボーナス = 2G × min(連敗数, 4)
    受取額 = 順位の基本賞金 + 連敗ボーナス
```

| 今回を含む連敗数 | 追加賞金 |
| --- | --- |
| 1 | 2G |
| 2 | 4G |
| 3 | 6G |
| 4以上 | 8G |

勝ったときに以前の連敗ボーナスを上乗せしない。連勝ボーナスも設けない。これは本ゲームの試作用の式で、他作品の現行計算式を再現したものではない。

4連敗中の2位は計20Gとなり、1位と同額になる。順位による先行権は違うが、2位維持の方が経済的に有利になりすぎる危険がある。係数2G、上限8G、基本賞金差を優先して検証する。

### 会計タイミング

賞金は試合終了時に1回だけ支払う。次のラウンド開始時には投資配当だけを支払い、前回賞金を再加算しない。初回の準備では初期資金のみを使用する。

## 4. 投資の回収計算

総ラウンド数をR、購入ラウンドをr、費用をC、1回の配当をdとすると、派閥補正を除く投資単体の純収支は次式。

```text
配当回数 = R - r
投資単体の純収支 = d × (R - r) - C
```

R=15、r=1、C=8、d=2なら配当合計28G、購入費を引いた純収支20G。ただし、ワーカー1個を使う機会費用や、手元資金の減少はこの値に含まない。

同じ手番で銀行の4Gを取れたなら、その選択との金銭差は次式。

```text
銀行との差 = d × (R - r) - C - 4
```

1件目の投資は単体では4回の配当で元本回収するが、銀行との金銭比較で並ぶには6回の配当が必要。VPや他マスを取れた場合の価値はさらに別途考える。

序盤の投資は有利になりやすい。購入価格逓増・保有上限だけで十分か、投資マスの容量と早期争奪も含めて測定する。ワーカー増員にも同様の早期優位がある。

## 5. エコとフォースバイの比較

エコは単なる「毎回負ける」戦略ではなく、試合に使う資源を絞る選択。

| 方針 | 主な支出 | 狙い | リスク |
| --- | --- | --- | --- |
| フルバイ | 強いカード・手札に合うルール | 賞金と次回先行権 | 勝っても支出が賞金差を超える |
| エコ | 安価なカードだけ、または確保なし | 貯金・投資・VPへ資源を回す | 後手になり重要マスを失う |
| ハーフバイ | 永続スキルと一部のカード | 今回と将来の両立 | どちらにも投資不足になる |
| 派閥成長 | 支援・外交 | バフ・専用VP・同盟 | 回収が遅く、相手にも共有効果を与える |
| 直接VP | 一般VP・派閥VP | 現在の得点を確定 | 次回以降の経済・先行権を失う |

比較では、賞金差だけでなく次回先行権の価値を測る。先行権のために勝ちたい状況を作る一方、先手が毎回全てを取れる容量にはしない。

## 6. 最終ラウンドの問題

試合賞金からVPを直接与えないため、最後の配置が終わった後に最終試合を行うだけでは、その賞金が得点に影響しない。

**未採用の推奨試行案**: 最終ラウンドだけ一般VP・派閥VPマスを試合前には閉じ、賞金精算後に開く。通常のワーカープールの未使用分で、最終試合の順位順に得点配置する。ワーカーも枠も二重に配布・回復しない。

この案では「最後の試合へ投資するか、最後の得点配置用ワーカーを残すか」が判断になる。ただし、終盤だけの例外処理が増えるため、最終回を配置のみとする案などと比較してから確定する。

現金の自動VP換算で済ませると、得点は配置から得るという方針を弱める。無断で導入しない。

## 7. 検証計画

### 比較する方針

カード勝利特化、節約・銀行特化、投資優先、技能優先、単一派閥集中、複数派閥展開、直接VP優先、状況適応の各方針を用意する。

序盤投資固定、毎回2位狙い、毎回最下位、同盟だけを奪う終盤戦術も意図的に試す。「エコが使える」ことと「常時エコだけが最善」であることを区別する。

### 記録する指標

| 指標 | 見たい問題 |
| --- | --- |
| 最終VPとその内訳 | 特定の得点源だけで決着していないか |
| ラウンド別の現金・収支 | 資金の過不足と連敗救済の強さ |
| 投資・増員の購入ラウンド | 初手が固定されていないか |
| 配置順別のVP・勝率 | 勝者先行が固定的な有利を生まないか |
| 各マスの利用率・競合率 | 多すぎる市場枠と希少枠の関係 |
| エコ後の復帰率 | 貯金から再参入できるか |
| 同盟移転数・最終得点差 | 首位ポイントの奪取が過大でないか |
| 派閥契約率・解禁時期 | 商業一択、共有効果の早期全解禁にならないか |
| 配置時間・試合時間 | 15ラウンドの長さが許容できるか |
| 未使用ワーカー・余剰資金 | 有効な使い道がなくなる局面の有無 |

### 手順

まず会計とカード保存則を検証し、次に少数の手動プレイでルールの理解負荷を確認する。その後、同一乱数シードを使った比較と席順入れ替えで各方針を評価する。

試合部分を簡略な勝率モデルで置き換えた経済シミュレーションだけでは、大富豪本体のバランスは証明できない。最終的には合法手エンジンによる対戦結果と人間のプレイテストで確認する。
