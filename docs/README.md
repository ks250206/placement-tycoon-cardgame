## 仕様の状態

- **採用**: 会話で採用したゲームの仕組み。
- **試作案**: 動作やバランスの検証に使う候補。確定仕様ではない。
- **未決定**: 意味・方式・競合処理を確定してから実装する項目。

特に、4人・15ラウンド、5〜7ワーカー、各価格、賞金、連敗ボーナス係数、派閥の段階・共有効果閾値は試作値。

値を変更する際は、READMEと他文書の例示も更新する。特に同盟VPは累積VPと別管理し、試合賞金にVPを混ぜない。

## 優先的に詰める事項

最終試合の賞金を使う得点配置、ジョーカー確保方式、方縛り・両縛りの厳密な定義、共有ルールの併存制限、試合時間を先に確認する。

この版は設計文書のみ。ゲーム本体、シミュレータ、テスト実装、プレイテスト結果はまだ含まない。
