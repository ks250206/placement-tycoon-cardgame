# 派閥・影響力・同盟の設計

[設計書一覧](README.md) / [ゲーム設計書](game-design.md)

5派閥とそれぞれの役割、影響力トラック、派閥専用VPマス、首位の追加ポイント、全体共有効果は採用済み。以下の段階、閾値、効果量、発動タイミングは試作案であり、バランスは未検証。

## 1. 4つの機能を分ける

| 機能 | 対象 | 条件 | 主契約が必要か |
| --- | --- | --- | --- |
| 個人バフ | 本人だけ | 自分の影響力とラウンド開始時の契約 | 必要 |
| 共有効果 | 全プレイヤー | 派閥全体の解禁条件 | 不要 |
| 派閥VPマス | 配置した本人 | 自分の現在の影響力・資金・ワーカー | 不要 |
| 同盟トークン | 派閥の首位 | 必要影響力に達し、保持者を上回る | 不要 |

複数派閥を育ててもよい。主契約は個人バフの重ね掛けを抑えるための制約であり、他派閥への投資・得点・同盟保持を禁止する所属選択ではない。

## 2. 影響力トラック

各プレイヤーは、5派閥それぞれに0から始まる影響力を持つ。

| 影響力 | 試作上の意味 |
| --- | --- |
| 0 | 未開拓。個人バフなし |
| 1 | 主契約時の基本個人バフ |
| 2 | 主契約時の個人バフ強化 |
| 3 | 通常の派閥VP交換を利用可能 |
| 4 | 同盟トークン獲得の最低条件 |
| 5 | 上位個人バフと上級の派閥VP交換 |
| 6以上 | 同盟争奪を継続。数値上限は設けない試作案 |

影響力はラウンド終了時に消えない。現状は減少させるアクションを設けない。

「影響力2で固定1VP」の案は追加オプションとして保留し、既定OFF。基本の得点源はVP配置と同盟であり、共有効果の解禁でもVPを自動支給しない。

### 影響力を増やす配置先

- **派閥支援**: 各派閥に1枠。ワーカー1個と所定資金で、その派閥の影響力を+1。
- **外交**: 全体で2枠の試作案。ワーカー1個と通常費用に追加料金を払い、任意の派閥を+1。

外交は後手の追い上げ経路。保持者が毎回同じ支援枠を押さえるだけで、同盟が永久に固定されることを防ぐ。

複数枠への配置は可能だが、必ず1手番につき1個ずつ置く。1回の支払いで影響力を任意に買い上げることはできない。

## 3. 主契約と個人バフ

### 契約タイミング

毎ラウンドの準備時、影響力1以上の派閥から1つを選ぶ。条件を満たす派閥がなければ契約なし。選択にワーカーや追加料金は使わない試作案。

契約と個人バフの段階は、配当・カード確保・配布より前に固定する。その後に影響力が上がっても、個人バフの新段階は次ラウンドから適用する。ただし、派閥VPアクセスと同盟判定は現在の影響力を使い、配置直後に更新する。

以下の「最初の購入」は、そのラウンドにおける本人の対象カテゴリの購入を指す。割引による支払額の下限は1Gとする試作案。

| 派閥 | 影響力1 | 影響力2〜4 | 影響力5以上 |
| --- | --- | --- | --- |
| 王党派 | 最初のA・2・K確保を1G割引 | 同じ対象を2G割引 | 最初の2回のA・2・K確保をそれぞれ2G割引 |
| 革命派 | 最初の共有ルール購入を1G割引 | 同じ対象を2G割引 | 最初の2回の共有ルール購入をそれぞれ2G割引 |
| 商業ギルド | 最初の銀行利用の受取額+1G | 最初の銀行利用の受取額+2G | 左記に加え、投資保有時に配当合計+1G |
| 技能ギルド | 最初のスキル購入を1G割引 | 同じ対象を2G割引 | 左記に加え、そのラウンドの装備枠+1 |
| 諜報組織 | 配布後、未配布カードとの盲目的な1枚交換が可能 | 未配布カード1枚を見て、交換するか選べる | 未配布カード2枚を見て、いずれか1枚と交換するか選べる |

各段階は前段階を置き換える。王党派の影響力2で「1G+2G」の個人割引にはならない。商業ギルドの上位配当は投資1件ごとではなく、配当総額に1Gだけ加える。

### 王党派: 手札の質への投資

強い通常ランクの確保を安くし、試合賞金と次回先行権を狙う。革命が起きれば、確保した高ランクの価値が変わる。

ジョーカー、♠3はこの割引の対象外。ジョーカー購入方式が未決定であることとも分離する。

### 革命派: 共有環境への投資

手札を確認してからルールを安く解禁できる。ただし恩恵は自分専用ではない。革命購入で即座に反転したり、相手の購入済みルールを無効にしたりする権限は持たない。

### 商業ギルド: 資金循環への投資

銀行と投資を支えるが、VPを自動生成しない。稼いだ資金を得点に変えるには、別途VPマスとワーカーが必要。

個人銀行ボーナスは各ラウンド最初の1回だけ。共有銀行ボーナスは、後述のとおり全員の各利用に適用する。

### 技能ギルド: 能力構築への投資

永続スキルの獲得と装備を支える。スキルを失わずに主契約を切り替えられるが、追加装備枠は技能ギルドとの契約が有効なラウンドだけ。

通常3枠・契約上位4枠の試作案。契約を変えて枠が減ったら、試合前に装備し直す。購入したスキルそのものは失わない。

### 諜報組織: 配布後の情報と調整

配布済みの自分の手札を見てから、未配布プールへ干渉する。相手の手札を無条件で閲覧する能力ではない。

試作では偵察に追加ワーカーを要求せず、ラウンド1回の契約能力とする。複数人が利用する場合は配置順に解決し、現在の未配布プールを参照する。

交換は必ず1対1。手札は13枚、未配布プールは2枚を維持する。自分が戻したカードは以後の交換候補になり、他の諜報利用者が受け取る可能性がある。

## 4. 全体共有効果

### 解禁の試作ルール

派閥ごとに、全プレイヤーの影響力を合計する。

```text
合計影響力 = その派閥に対する全プレイヤーの影響力の合計
合計影響力 >= 6 → 解禁予約
次ラウンド開始 → 共有効果を有効化
```

解禁後はゲーム終了まで有効とする試作案。閾値を再び超えるたびに報酬を得るわけではない。現在の仕様では影響力が減らないため、再封鎖処理は不要。

影響力0の人、他派閥と主契約している人、同盟を持っていない人にも適用する。5派閥の共有効果は同時に有効になり得る。

| 派閥 | 全体共有効果の試作案 |
| --- | --- |
| 王党派 | 全員の最初のA・2・K確保を1G割引 |
| 革命派 | 全員の最初の共有ルール購入を1G割引 |
| 商業ギルド | 全員の銀行利用の受取額を、利用ごとに+1G |
| 技能ギルド | 全員の最初のスキル購入を1G割引 |
| 諜報組織 | 配布直後、未配布プールの1枠を全員へ公開 |

### 個人効果との合算

同じ購入に個人割引と共有割引が適用される場合は合算し、最後に支払下限を適用する。

```text
支払額 = max(1, 基本価格 - 個人割引 - 共有割引)
```

例: 基本6Gの2を、王党派の影響力2で最初に購入し、王党派の共有効果も有効なら3G。

銀行基本4G、商業の共有効果+1G、個人バフ+2Gなら最初の銀行は7G。同ラウンドの2回目は個人の回数制限により5G。

これらは他のマスの容量を増やさない。共有効果が解禁されても、既に埋まった銀行を使えるようにはならない。

### 公開プールの扱い

諜報の共有効果は、2枚のうち固定の公開スロットを1つ設ける。そこから交換が行われたら、戻されたカードも公開する。もう一方のスロットは、個人の偵察などで見たプレイヤー以外には非公開のまま。

既知カードの情報は交換で古くなり得る。実装では、以前見たカードと現在そこにあるカードを区別する。

## 5. 派閥専用VPマス

各派閥につき**合計1枠**のVPマスを持つ試作案。通常と上級は別マスではなく、同じ枠で選べる交換メニューとする。

| 交換 | 必要影響力 | 試作価格 | 得点 |
| --- | --- | --- | --- |
| 通常 | 3以上 | 12G | 2VP |
| 上級 | 5以上 | 19G | 3VP |

1回の配置でどちらか一方を選ぶ。同じラウンドに別の人が通常交換と上級交換をそれぞれ使うことはできない。

同盟保持者だけの専用枠ではない。条件を満たす全員で先着順に争う。同盟を持っていても優先予約や自動利用はできない。

VP利用資格は現在の影響力を参照するため、第2配置で影響力を3へ上げ、その後の自分の手番でVPマスへ置くことは可能。

## 6. 同盟トークンと首位ボーナス

「1番手への追加ポイント」は、各派閥の影響力首位が持つ同盟トークンとして実現する。大富豪の1位へのVPではない。

試作では各派閥に1枚、各2VPとする。

1. まだ保持者がいなければ、最初に影響力4へ到達した人が獲得する。
2. 保持者がいる場合、他の人がその影響力を**厳密に上回る**と移転する。
3. 同点では現在の保持者が維持する。
4. 移転時は元の保持者の同盟VPを減らし、新保持者に同量を加える。
5. 複数派閥の同盟を同時に持てる。主契約と一致していなくてもよい。
6. 毎ラウンドの継続保持による追加加点はない。

例: 王党派のAが影響力5、Bが4。Bが支援で5にしても移転しない。さらに外交で6にすればBへ移り、Aは2VP減、Bは2VP増となる。

## 7. バランス上の観測点

同盟1枚の移転は、2人の得点差を4VP動かす。表示上の2VPより終盤の影響が大きいため、奪取に必要な費用とワーカーを必ず一緒に評価する。

共有効果への投資は、ライバルへの便益も生む。単に全派閥が早々に解禁されるだけになっていないか、解禁直前の駆け引きがあるかを観測する。

複数派閥への横展開、1派閥への集中、主契約の変更、後手の外交、同盟を追わずにVP利用資格だけ取る方針を比較する。詳細な指標は [経済・バランス設計](economy-and-balance.md) を参照。
